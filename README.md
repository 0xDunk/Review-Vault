# 🎬 Review Vault

A full-stack web application where users can browse, review, and rate movies.

## 🚀 Features

- 🔐 User Authentication (Register & Login)
- 🎥 Browse movie reviews
- ⭐ Review movies
- 📝 Create, edit, and delete reviews
- 📱 Responsive design

## 🛠️ Tech Stack

### Frontend
- HTML
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

## 📂 Project Structure

```
Backend/
├── config/
├── middleware/
├── models/
├── public/
├── routes/
├── uploads/
├── utils/
├── views/
├── server.js
└── package.json
```
